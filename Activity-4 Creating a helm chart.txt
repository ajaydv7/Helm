########################################################################################
Create Helm Charts
########################################################################################

Step 1: To generate a chart
=> helm create nginx-demo

Step 2: Check the files generated by above command

Step 3: Delete all the files in template folder
=> rm -rf templates/*

Step 4: For adding our own custom files, create deployment.yaml file in templates folder and paste the below content
=> vi deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}-nginx
  labels:
    app: nginx
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: {{ .Chart.Name }}
          image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
          imagePullPolicy: {{ .Values.image.pullPolicy }}
          ports:
            - name: http
              containerPort: 80
              protocol: TCP
          volumeMounts:
            - name: nginx-index-file
              mountPath: /usr/share/nginx/html/
      volumes:
      - name: nginx-index-file
        configMap:
          name: nginx-html-configmap

Step 5: Also create service.yaml and paste below content
=> vi service.yaml
apiVersion: v1
kind: Service
metadata:
  name: {{ .Release.Name }}-service
spec:
  selector:
    app: nginx
  type: {{ .Values.service.type }}
  ports:
    - protocol: {{ .Values.service.protocol | default "TCP" }}
      port: {{ .Values.service.port }}
      targetPort: {{ .Values.service.targetPort }}

Step 6: Create configmap.yaml and paste below content
=> vi configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: nginx-html-configmap
  namespace: default
data:
  index.html: |
    <html>
    <h1>Welcome</h1>
    </br>
    <h1>Hi! I got deployed in {{ .Values.env.name }} Environment using Helm Chart </h1>
    </html>

Step 7: In the values.yaml file, we will provide all the values which we want to pass to the files in templates directory

replicaCount: 2

image:
  repository: nginx
  tag: "1.16.0"
  pullPolicy: IfNotPresent

service:
  name: nginx-service
  type: LoadBalancer
  port: 9000
  targetPort: 80

env:
  name: dev

Step 8: Verify Formatting of all the helm files is in a proper way or not
=> helm lint .

Step 9: Install nginx-demo
=> helm install helm-demo nginx-demo

Step 10: Check the release list
=> helm list

Step 11: To check the deployment, services, and pods.
=> kubectl get deployment
=> kubectl get services
=> kubectl get configmap
=> kubectl get pods

Step 12: If we want to do any changes to above release , like we don't want 2 replicas. Decrease the replicas count in values.yaml file
=> helm upgrade helm-demo nginx-demo

Step 13: If we wish to undo the changes
=> helm rollback helm-demo

Step 14: For checking the history of release
=> helm history helm-demo
